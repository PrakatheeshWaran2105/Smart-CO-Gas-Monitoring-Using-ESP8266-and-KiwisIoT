# Smart-CO-Gas-Monitoring-Using-ESP8266-and-KiwisIoT
Smart CO Gas Monitoring using ESP8266 and MQ-7 sensor with real-time carbon monoxide level monitoring and data visualization through the KiwisIoT platform.
Smart CO Gas Monitoring Using ESP8266 and KiwisIoT
About the Project
The Smart CO Gas Monitoring System is an IoT-based project designed to detect and monitor carbon monoxide (CO) gas levels in the surrounding environment in real time.

Using a NodeMCU ESP8266 microcontroller and an MQ-7 carbon monoxide sensor, the system detects CO gas concentration and transmits the sensor readings to the KiwisIoT platform through Wi-Fi. Users can remotely monitor gas level readings through an online dashboard and observe changes in the surrounding air quality.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to gas monitoring, real-time data visualization, and IoT-based environmental safety applications.
